# Retired VNPay integration

VNPay sandbox was retired on November 3, 2026. This path remains only so historical handoff links do not send developers to obsolete setup instructions. No VNPay endpoint, signer, configuration, or checkout is active.

Use [payOS VietQR payments](payos-payments.md). Historical database rows with `provider = 'vnpay'` are deliberately preserved for audit and financial history.
