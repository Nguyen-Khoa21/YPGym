## How to use this vault

- New package spec: create it from the `spec-package` template in `Templates`.
- New decision: use the `decision` template and add a row to [[Decisions Log]].
- Daily notes land in `05 Daily log` using the `daily-log` template.
- Keep how-to-run and coding rules in the repo (`AGENTS.md`, `RUN_GUIDE.md`). Link to them here instead of copying them.
- Statuses used in package notes: `implemented-verified`, `partially-implemented`, `committed` (commit exists, no verification recorded in the spec), `planned`.
